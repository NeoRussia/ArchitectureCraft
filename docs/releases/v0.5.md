A rendering patch. It makes redrawing a build of shapes cheap, so placing and
breaking blocks next to one no longer stalls the game.

Fixes
-----
- **Building next to shapes no longer stutters.** Redrawing a chunk that holds
  shapes read the world's light once per vertex, and re-read each shape's own
  light value for every sampled cell; repeated neighbour checks behind the
  translucent seam culling cost a full re-render each time. The light is now
  read once per shape and remembered per cell, and the neighbour checks are
  cached. A dense wall re-bakes roughly three to four times faster: a freeze
  that felt like two seconds in our test world fell below half a second.
  Roof and window shapes read their neighbours while drawing, so they are
  deliberately left uncached and look exactly as before.

Requirements and install
------------------------
- Minecraft 1.12.2, Forge 14.23.5.2860, Java 8. Cleanroom 0.7.x works too.
- No dependencies.
- Drop the jar into `mods/` and start the game. Existing worlds keep their
  shapes and their orientation.
